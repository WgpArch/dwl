# ⌨️ Keybinds

Here are the default keybindings for this dwl setup. The main modifier key is `Super` (Windows key).

## 🖥️ Programs & System

| Keybind | Action |
| :--- | :--- |
| `Super + Return` | Open Terminal (`lxterminal`) |
| `Super + P` | Open App Launcher (`rofi` sleek-dark theme) |
| `Super + B` | Open Firefox |
| `Super + Shift + Q` | Close focused window |
| `Super + Shift + C` | Quit dwl |
| `Super + Shift + S` | Take screenshot (custom script) |

## 🔍 Focus & Movement

| Keybind | Action |
| :--- | :--- |
| `Super + J / K` | Focus next/previous window |
| `Super + I / D` | Increase/Decrease number of master windows |
| `Super + H / L` | Shrink/Expand master area (mfact) |
| `Super + Shift + Return` | Zoom (move window to master area) |
| `Super + Tab` | View previously selected tags |

## 🗂️ Tags (Workspaces)

| Keybind | Action |
| :--- | :--- |
| `Super + [1-9]` | View tag 1-9 |
| `Super + Ctrl + [1-9]` | Toggle view of tag 1-9 |
| `Super + Shift + [1-9]` | Move window to tag 1-9 |
| `Super + 0` | View all tags |

## 📐 Layout & Gaps

| Keybind | Action |
| :--- | :--- |
| `Super + T` | Set Tiling layout |
| `Super + E` | Set Floating layout |
| `Super + M` | Set Monocle layout |
| `Super + Space` | Cycle layouts |
| `Super + Shift + Space` | Toggle floating for active window |
| `Super + F` | Toggle fullscreen |
| `Super + G` | Toggle gaps on/off |

## 🔊 Media & System Keys

| Keybind | Action |
| :--- | :--- |
| `Volume Up/Down` | Volume 5% +/- (`wpctl`) |
| `Mute` | Toggle audio mute |
| `Brightness Up/Down` | Backlight +/- 30 (`brightnessctl`) |
